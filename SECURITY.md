Security

NeuSE handles where people are during searches, so security problems matter. Thank you for reporting one.

Reporting a problem

Please do not open a public issue. Use GitHub's private reporting instead, on the repository's Security tab, Report a vulnerability. Say what you found, how to see it happen, and what it could let someone do. You should hear back within a week.

What is covered

- The field unit code in `src/` and `dashboard/`
- The command center in `command_center/`
- The deployment files in `deploy/`
- The trained model files in `models/` and the training scripts in `scripts/`

What NeuSE already does

`docs/SAFETY.md` lists the threats NeuSE is built against, the measures taken and the risks that remain.

Supported versions

Only the newest code on the `main` branch gets fixes.
